# Contributing

Run `npm ci`, `npm run typecheck`, `npm test`, and `npm run check:public` in `mobile-react-native` before submitting a change. For native changes also compile the Android project.

Keep this edition free of bundled playback sources, activation mechanisms, source download services, credentials and personal test data. Use synthetic test fixtures and reserved example domains. Preserve playback validation and the single-player architecture when changing source selection.

Contributions are accepted under the root Apache License 2.0 and the project terms in README. Retain existing third-party attribution and identify the origin and license of any newly introduced external code or assets.
