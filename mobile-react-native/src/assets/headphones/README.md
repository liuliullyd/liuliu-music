# AutoEq headphone calibration catalog

Upstream: https://github.com/jaakkopasanen/AutoEq

Snapshot: 7ae0f56d53074872b028649617a22bbb4232feb7.

The catalog contains manufacturer and model metadata. Android calibration profiles live in android/app/src/main/assets/headphones and load on demand. sync-manifest.json records upstream provenance; targets.json preserves target-curve metadata.

Retain AutoEq-LICENSE.txt and license.json when redistributing these files. This public edition uses text labels and excludes manufacturer logo images.
