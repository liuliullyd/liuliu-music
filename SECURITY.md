# Security

Do not include passwords, signing keys, source scripts with credentials, account cookies, device identifiers, personal playlists or unredacted logs in public issues.

Use GitHub private vulnerability reporting when enabled by the repository owner. Until a private reporting channel is available, open a minimal issue asking the maintainer for a private contact without publishing exploit details or secrets.

Imported scripts can perform network requests through the native bridge. Review scripts before importing them. The project does not operate a source server or issue activation codes.
